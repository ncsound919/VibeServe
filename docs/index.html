Quick Start

Get started with VibeServe in minutes

# Install VibeServe
npm install -g vibeserve

# Start the server
vibeserve start

# Use with MCP client
# Example: call web_scraper tool
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "web_scraper",
    "arguments": {
      "url": "https://example.com"
    }
  },
  "id": 1
}
