Quick Start

1. Install

pip install vibeserve

2. Configure (optional — works with zero API keys)

# Set your preferred LLM provider
export DEFAULT_LLM_PROVIDER=openai
export OPENAI_API_KEY="sk-..."

# Or use local models for free:
export DEFAULT_LLM_PROVIDER=local
export LOCAL_LLM_URL="http://localhost:11434/v1"

3. Add to Claude Desktop

{
  "mcpServers": {
    "vibeserve": {
      "command": "vibeserve"
    }
  }
}

4. Use interactively

vibeserve --interactive
