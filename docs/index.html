All 11 MCP Tools

Drop into any MCP-compatible client — Claude Desktop, Cursor, Windsurf, or custom.

vibe_architect
Transforms natural language intent into a full architecture plan with ADR decisions, component tree, data flow, risk assessment, and recommended stack.
vibe_code
Generates production-ready TypeScript/JSX code from a VibePlan. Enforces design tokens, ARIA attributes, and accessibility notes on every file.
vibe_review
Three-agent parallel code review: UX Designer, Code Quality Engineer, and Accessibility Advocate — each gives independent scores and line-level issues.
vibe_verify
Static validation: UISchema v1.0 compliance, WCAG contrast checks, ARIA coverage, and code quality flags (TODO/FIXME, missing accessibility notes).
vibe_iterate
Continuous improvement loop. Critiques, repairs weaknesses, re-evaluates — up to N iterations or until the quality threshold is reached.
vibe_test
Generates full test suites from source code: unit, accessibility, integration, edge cases, and responsive breakpoint tests.
vibe_deploy
Generates deployment configs for Vercel, Docker, static hosting, and Node.js. Includes env vars, health checks, and monitoring setup.
generate_ui_spec
V4 pipeline: generates UISchema v1.0 specs with multi-agent critique, WCAG AAA validation, and design system token enforcement.
validate_ui_spec
Validates any UISchema v1.0 document. Returns errors, warnings, and per-component contrast ratio checks.
list_design_systems
Lists available design systems (built-in and custom). Returns color palettes, component counts, and WCAG level per system.
memory_stats
Returns aggregate stats on the SQLite-backed spec memory store: total stored, highest scores, usage by page type.

Quickstart

Running in 60 seconds.

1. Clone & install

git clone https://github.com/ncsound919/AetherNexus-MCP cd AetherNexus-MCP pip install -e ".[dev]"

2. Configure environment

cp .env.example .env # Add your OPENAI_API_KEY, DEEPSEEK_API_KEY, or leave blank for local/sampling

3. Add to Claude Desktop (claude_desktop_config.json)

{ "mcpServers": { "vibeserve": { "command": "python", "args": ["/path/to/AetherNexus-MCP/mcp_ui_optimizer_v4.py"] } } }

4. Run tests

pytest test_aether_nexus.py test_integration_v5.py -v # 43 tests. All pass.
