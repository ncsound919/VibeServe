VibeServe MCP

Open-source MCP server with 28 tools for AI agents. Interact with files, web, and APIs seamlessly.

Features & Tools

File System

Read, write, list files and directories. Full CRUD operations.

Web Search

Search the web and fetch page content with markdown conversion.

API Integration

Make HTTP requests to any REST API with authentication support.

Code Execution

Run JavaScript, Python, and shell commands in sandboxed environment.

Data Processing

Parse CSV, JSON, XML. Transform data between formats.

Image Manipulation

Resize, compress, convert images. Generate thumbnails.

Quick Start

# Install via npm
npm install -g @vibeserve/mcp

# Start the server
vibeserve start

# Or use npx
npx @vibeserve/mcp start
