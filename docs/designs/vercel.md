# Vercel Design System
- Pure white canvas (#ffffff), Vercel Black text (#171717, not pure black)
- Geist Sans at display: 48px/600, aggressive -2.4px letter-spacing
- Shadow-as-border: `0px 0px 0px 1px rgba(0,0,0,0.08)` replaces borders globally
- Multi-layer shadows: border + elevation + ambient + inner #fafafa glow ring
- Workflow accents: Ship Red #ff5b4f, Preview Pink #de1d8d, Develop Blue #0a72ef
- Pill badges (9999px) for status, 6px radius buttons, 8-12px cards
- Gallery emptiness — massive whitespace between compressed text blocks
