# Stripe Design System
- White canvas (#ffffff), deep navy headings (#061b31, not black)
- Stripe purple (#533afd) as primary CTA — saturated, premium
- sohne-var font with ss01 stylistic set; weight 300 as signature headline weight
- Blue-tinted multi-layer shadows: rgba(50,50,93,0.25) far + rgba(0,0,0,0.1) near
- Conservative radius: 4-8px only — never pill for buttons
- Light-dark section rhythm: white bands alternate with brand dark (#1c1e54)
- Shadow colors echo brand navy — elevation feels on-brand
