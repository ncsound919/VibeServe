# VibeServe Scripts

One-off utilities for development and testing.

## Scripts

| Script | Description |
|--------|-------------|
| `benchmark.py` | Quick performance benchmark |
| `benchmark_system.py` | Full system benchmark with scoring |
| `run_loop.py` | Run the agentic pipeline in a loop |
| `split_main.py` | Entry point for MCP server |
| `demo_e2e.py` | E2E demo runner |
| `vibeserve.py` | Legacy entry point |

Run any script with `python scripts/<script>.py`.
