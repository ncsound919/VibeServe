# Linear Design System
- Dark-canvas (#010102), charcoal cards (#0f1011), hairline borders (#23252a)
- Lavender-blue primary (#5e6ad2), never decorative
- Display: Linear custom sans, 80px/600/-3.0px tracking → body 16px/400
- Cards: surface-1 bg, lg rounded (12px), 1px hairline borders
- Buttons: primary lavender, secondary charcoal, md rounded (8px), 8px/14px padding
- No shadows — depth from surface ladder (canvas→surface-1→surface-2→surface-3→surface-4)
- Product UI screenshots as hero content, not abstract illustrations
