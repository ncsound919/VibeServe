# Supabase Design System
- Dark-mode-native: near-black (#0f0f0f, #171717), never pure black
- Emerald green (#3ecf8e, #00c573) as brand identity marker — borders, links, small accents
- Circular font, 72px hero at 1.00 line-height, weight 400
- Source Code Pro uppercase technical labels (1.2px letter-spacing)
- No shadows — depth from border hierarchy: #242424 → #2e2e2e → #363636
- Pill buttons (9999px) for CTAs, 6px radius secondary, 8-16px cards
- HSL-based color tokens with alpha channels for translucent layering
