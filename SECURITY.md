# Security Policy

If you discover a security vulnerability in this project, please report it privately. Do not open a public issue.

## Reporting a Vulnerability

Please email your report to [ncsound919@gmail.com](mailto:ncsound919@gmail.com). We will acknowledge receipt of your report within 48 hours and work with you to remediate the issue.

We are committed to resolving all security vulnerabilities in a timely manner. Thank you for your contribution to the project's security.
