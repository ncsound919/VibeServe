Get Shit Done workflow. Available GSD commands:
- /gsd-help - Show all GSD commands
- /gsd-new-project - Initialize new GSD project
- /gsd-discuss-phase N - Capture implementation decisions
- /gsd-plan-phase N - Research + plan + verify
- /gsd-execute-phase N - Execute all plans in parallel waves
- /gsd-verify-work N - User acceptance testing
- /gsd-progress - Where am I? What's next?
- /gsd-quick - Execute ad-hoc task with GSD guarantees
